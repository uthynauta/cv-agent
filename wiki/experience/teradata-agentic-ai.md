# Teradata — AI Engineer / Agentic AI Platform Engineer
- **Dates:** December 2025 – July 2026
- Developed core capabilities for an internal enterprise Agentic AI platform supporting agent development, execution, evaluation, observability, and reusable skill integration.
- Engineered LangGraph workflows with structured tool execution, reusable agent skills, MCP integrations, and Retrieval-Augmented Generation.
- Contributed to a scalable architecture initially supporting five production agents and designed for additional agents and reusable skills.
- Designed OpenTelemetry-based telemetry for token usage, model cost, latency, errors, model metadata, tool calls, execution paths, and agent outcomes.
- Integrated Grafana, Prometheus, Loki, and distributed tracing for debugging, performance analysis, operational visibility, and AI FinOps.
- Built evaluation and analytics pipelines with PostgreSQL, pgvector, and DeepEval for agent assessment, dataset generation, failure analysis, and model-routing decisions.
- Developed Python and FastAPI backend services, plus Docker Compose and Kubernetes environments for development, testing, and production deployment.
