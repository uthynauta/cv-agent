# Teradata Agentic AI Platform
- Role: AI Engineer / Agentic AI Platform Engineer.
- Period: Dec 2025–Jul 2026.
- Contributed to an internal enterprise platform for deploying, consuming, evaluating, and observing AI agents.
- Engineered LLM workflows with LangGraph, structured tool execution, reusable agent skills, MCP-based integrations, and [[concepts/retrieval-augmented-generation|Retrieval-Augmented Generation]].
- Designed observability and distributed tracing with OpenTelemetry, including token usage, latency, cost, errors, model metadata, tool calls, execution paths, and agent outcomes.
- Managed Grafana, Prometheus, Loki, and tracing pipelines for debugging, performance analysis, and FinOps.
- Built telemetry and evaluation pipelines with PostgreSQL/pgvector and DeepEval for agent evaluation, analytics, dataset generation, and model routing.
- Developed containerized and cloud-native environments with Docker Compose and Kubernetes fundamentals.
