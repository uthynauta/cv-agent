# LLM Observability
- The CV describes an OpenTelemetry-based architecture for standardizing telemetry across multi-step LLM and agent workflows.
- Captured token usage, model cost, latency, errors, model metadata, tool calls, execution paths, and agent outcomes.
- Integrated Grafana, Prometheus, Loki, and distributed tracing pipelines for debugging, performance analysis, operational visibility, and AI FinOps.
- Defined telemetry schemas and event models for agent, graph, model, prompt, tool, and skill metadata.
- The schemas supported redaction and controlled storage of sensitive information.
