# LLM Observability and Evaluation
- The CV describes an OpenTelemetry-based architecture for capturing token usage, model cost, latency, errors, model metadata, tool calls, execution paths, and agent outcomes across multi-step workflows.
- Grafana, Prometheus, Loki, and distributed tracing pipelines supported debugging, performance analysis, operational visibility, and AI FinOps.
- Evaluation and analytics pipelines used PostgreSQL, pgvector, and DeepEval for agent assessment, dataset generation, failure analysis, and performance-informed model routing.
- Telemetry schemas recorded agent, graph, model, prompt, tool, and skill metadata with redaction and controlled storage of sensitive information.
