# Observability and Agent Evaluation
- The CV describes telemetry for token usage, latency, cost, errors, model metadata, tool calls, execution paths, and agent outcomes.
- Technologies and tools include OpenTelemetry, Grafana, Prometheus, Loki, PostgreSQL/pgvector, and DeepEval.
- The stated purposes are debugging, performance analysis, FinOps, analytics, dataset generation, and performance-driven model routing.
- Related experience: [[Teradata — AI and Agentic AI Platform Engineering]].
