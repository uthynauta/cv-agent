# Agent Observability
- The CV describes observability for LLM-based agents as the collection and analysis of execution telemetry and distributed traces.
- Tracked dimensions include token usage, latency, cost, errors, model metadata, tool calls, execution paths, and agent outcomes.
- Technologies named in the source include OpenTelemetry, Grafana, Prometheus, Loki, PostgreSQL/pgvector, and DeepEval.
- Used for debugging, performance analysis, FinOps, agent evaluation, analytics, dataset generation, and performance-driven model routing.
- Related project: [[projects/teradata-agentic-ai-platform|Teradata Agentic AI Platform]].
